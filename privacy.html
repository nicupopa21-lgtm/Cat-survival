This Privacy Policy explains how Cat Survival handles information in the Android game.

Summary

Cat Survival does not require an account, does not ask for your name, does not ask for your email address, does not use precise location, does not access contacts, and does not use the camera or microphone.

The game uses local storage on your device for save data and settings. If you accept analytics consent, the game may also use Firebase/Google Analytics for automatic app analytics events and limited custom gameplay analytics.

Local game data

The game may save gameplay progress and settings locally on your device so the game can continue between sessions. This may include level progress, upgrades, prestige or collapse progress, unlocked features, music or visual settings, and similar game state.

You can delete local game data by uninstalling the app or by using Android system settings to clear the app's storage/data.

Firebase/Google Analytics

The game uses Firebase/Google Analytics only when analytics consent is accepted. Analytics is used to understand basic app usage, game balance, progression difficulty, session length, technical behavior, and release quality.

When analytics collection is enabled, Firebase/Google Analytics may collect automatic app analytics events, such as first open or first start, session start, user engagement, app update, app clear data, and app removal or uninstall-related analytics where Firebase/Google Analytics reports those events.

The game may also send a custom gameplay event named cat_session_summary. This event may include these custom gameplay parameters: session_seconds, session_seconds_bucket, max_level, prestige_number, and collapse_number.

Firebase/Google Analytics may also process technical information needed to provide analytics services, such as app version, app instance or installation identifiers, device and app information, operating system information, Firebase SDK information, approximate usage timing, session identifiers, and diagnostic or event metadata. The exact data handled can depend on the Firebase SDK version and app configuration.

The game does not intentionally send your name, email address, phone number, address, contacts, photos, messages, payment details, save file, skill tree choices, or precise location to Firebase/Google Analytics.

Analytics consent and choices

The app uses a consent screen for analytics. If you deny analytics consent, the game should not use Firebase/Google Analytics for optional gameplay analytics collection.

If the game version includes an analytics option, you can change your analytics choice in the Options or Privacy/Data section of the game. If that option is not available in your version, you can reset your analytics choice by clearing the app's storage/data in Android settings or by uninstalling and reinstalling the app, then choosing your preferred analytics option when asked again.

How information is used

Local game data is used to run the game, save progress, remember settings, and provide gameplay features.

Analytics data is used to understand game balance, session length, progression difficulty, technical behavior, and whether players are reaching key game milestones. Analytics data is not used for ads or personalized advertising in the version covered by this policy.

Sharing of information

Player data is not sold.

Analytics data is processed by Google Firebase/Google Analytics as a service provider for analytics and app measurement. Firebase and Google Analytics may process data according to Google's Firebase terms, privacy, and data processing documentation.

Advertising, purchases, accounts, and cloud saves

The version covered by this policy does not include advertising, in-app purchases, user accounts, login, multiplayer chat, or cloud save accounts.

Children's privacy

The game does not intentionally collect personal information from children. If you believe a child has provided personal information through a support email or bug report, contact us and we will delete it where possible.

Data deletion

See the Data deletion page for steps to delete local game data, reset analytics consent, and contact us about data questions.

Changes to this policy

This Privacy Policy may be updated when the game changes, when Firebase configuration changes, or when legal or platform requirements change. The updated version will be posted on this page with a new effective date.
