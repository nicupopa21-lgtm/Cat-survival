This Privacy Policy explains how Cat Survival handles information in the Android game.

Summary

Cat Survival is designed as an offline-style Android game. The current version does not require an account, does not ask for your name, does not ask for your email address, does not use precise location, does not access contacts, and does not use the camera or microphone.

The current version uses local game storage on your device and Firebase Analytics for limited gameplay analytics when analytics consent is accepted.

Information stored locally on your device

The game may save gameplay progress and settings locally on your device so the game can continue working between sessions. This may include information such as level progress, upgrades, prestige/collapse progress, unlocked features, music or visual settings, and similar game state.

This local game data stays on your device unless you back up or transfer your device using Android or Google services outside this app. You can delete local game data by uninstalling the app or using Android system settings to clear the app's storage/data.

Firebase Analytics

The game uses Google Firebase Analytics to understand general gameplay behavior and improve balance, stability, and release quality.

When analytics collection is enabled, the game may send limited gameplay statistics such as session duration, maximum level reached, prestige number, collapse number, and similar non-personal game progression events. These events are used to understand whether progression, balance, and game length are working as intended.

Firebase Analytics may also process technical information needed to provide analytics services, such as app instance identifiers, device and app information, operating system information, Firebase SDK information, approximate usage timing, and diagnostic or event metadata. The exact data handled can depend on the Firebase SDK version and app configuration.

The game does not intentionally send your name, email address, phone number, address, contacts, photos, messages, or precise location to Firebase Analytics.

For more information about Firebase privacy and data handling, see Google's Firebase privacy information and Firebase Android data disclosure documentation:

  • Firebase Privacy and Security
  • Firebase Android data disclosure information

Analytics consent and choices

The current app version uses a consent screen for analytics. If you deny analytics consent, the game should not use Firebase Analytics for gameplay analytics collection.

If you previously accepted analytics and later want to withdraw consent before an in-app opt-out setting is available, you can clear the app's storage/data in Android settings or uninstall and reinstall the app, then deny analytics when asked again. You can also contact us for help.

A future version may add an in-app analytics opt-out toggle inside the settings/options menu. This policy should be updated when that feature is released.

How information is used

We use local game data to run the game, save progress, remember settings, and provide gameplay features.

We use analytics data to understand game balance, session length, progression difficulty, technical behavior, and whether players are reaching key game milestones.

Sharing of information

We do not sell player data.

Analytics data is processed by Google Firebase as a service provider for analytics and app measurement. Firebase may process data according to Google's Firebase terms, privacy, and data processing documentation. We do not link Firebase Analytics to advertising services unless this policy is updated to say so.

Advertising, purchases, accounts, and cloud saves

The current version covered by this policy does not include advertising, in-app purchases, user accounts, login, multiplayer chat, or cloud save accounts.

If any of those features are added later, this Privacy Policy should be updated before release of that version.

Children's privacy

The game does not intentionally collect personal information from children. If you believe a child has provided personal information through a support email or bug report, contact us and we will delete it where possible.

Data deletion

See the Data deletion page for steps to delete local game data and contact us about data questions.

Changes to this policy

We may update this Privacy Policy when the game changes, when Firebase configuration changes, or when legal/platform requirements change. The updated version will be posted on this page with a new effective date.
