This Privacy Policy explains how Cat Survival handles information in the Android game.

Summary

Cat Survival does not require an account, does not ask for your name, does not ask for your email address, does not use precise location, does not access contacts, and does not use the camera or microphone.

The game uses local storage on your device for save data and settings. The game may also use Firebase Analytics for limited gameplay analytics when analytics consent is accepted.

Local game data

The game may save gameplay progress and settings locally on your device so the game can continue between sessions. This may include level progress, upgrades, prestige or collapse progress, unlocked features, music or visual settings, and similar game state.

You can delete local game data by uninstalling the app or by using Android system settings to clear the app's storage/data.

Firebase Analytics

The game uses Google Firebase Analytics to understand general gameplay behavior and improve balance, stability, and release quality.

When analytics collection is enabled, the game may send limited gameplay statistics such as session duration, maximum level reached, prestige number, collapse number, and similar non-personal game progression events.

Firebase Analytics may also process technical information needed to provide analytics services, such as app instance identifiers, device and app information, operating system information, Firebase SDK information, approximate usage timing, and diagnostic or event metadata. The exact data handled can depend on the Firebase SDK version and app configuration.

The game does not intentionally send your name, email address, phone number, address, contacts, photos, messages, or precise location to Firebase Analytics.

Analytics consent and choices

The app uses a consent screen for analytics. If you deny analytics consent, the game should not use Firebase Analytics for gameplay analytics collection.

If you previously accepted analytics and want to reset that choice, you can clear the app's storage/data in Android settings or uninstall and reinstall the app, then choose your preferred analytics option when asked again.

How information is used

Local game data is used to run the game, save progress, remember settings, and provide gameplay features.

Analytics data is used to understand game balance, session length, progression difficulty, technical behavior, and whether players are reaching key game milestones.

Sharing of information

Player data is not sold.

Analytics data is processed by Google Firebase as a service provider for analytics and app measurement. Firebase may process data according to Google's Firebase terms, privacy, and data processing documentation.

Advertising, purchases, accounts, and cloud saves

The version covered by this policy does not include advertising, in-app purchases, user accounts, login, multiplayer chat, or cloud save accounts.

Children's privacy

The game does not intentionally collect personal information from children. If you believe a child has provided personal information through a support email or bug report, contact us and we will delete it where possible.

Data deletion

See the Data deletion page for steps to delete local game data and contact us about data questions.

Changes to this policy

This Privacy Policy may be updated when the game changes, when Firebase configuration changes, or when legal or platform requirements change. The updated version will be posted on this page with a new effective date.
